# Bug Hunter

Android-игра в стиле **Doodle Jump**, в которой главный герой — эльф, поднимающийся всё выше по огромному бесконечному дереву.

## О проекте

Проект был разработан в **2021 году** для Android.

Основная механика построена вокруг прыжков по веткам дерева: игрок должен постоянно двигаться вверх, отталкиваясь от платформ и стараясь забраться как можно выше. По пути эльфу мешают различные насекомые, с которыми необходимо сражаться.

## Игровой процесс

* Прыжки и перемещение по веткам дерева.
* Бесконечное вертикальное восхождение.
* Сражения с насекомыми.
* Битвы с боссами.
* Получение игровой валюты.
* Покупка игровых предметов.
* Кастомизация персонажа.

## Игровые системы

В проекте реализованы:

* Система ежедневных наград.
* Игровая валюта.
* Магазин предметов.
* Профиль персонажа.
* Кастомизация внешнего вида персонажа.
* Система сражений.
* Боссы.
* Бесконечный уровень с вертикальным продвижением.

## Статус

**Архивный проект**

Проект был разработан в 2021 году и в настоящее время не развивается.

Исходный код проекта был утрачен в результате технического инцидента. На данный момент сохранилась только стабильная собранная версия игры для Android, которая и представлена в этом репозитории.
